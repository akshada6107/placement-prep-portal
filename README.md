# PrepPath - Placement Preparation Portal

A small React + Express + SQLite app: register/login, take an aptitude quiz, browse coding problems, and keep your saved results.

- `backend/` - Express server + SQLite database (port 5000)
- `frontend/` - React app built with Vite (port 5173)

See **EXPLAIN.md** for how to run it, what each file does, and viva answers.
